ตัวอย่างใน Kit นี้อาจมีเนื้อหามากกว่าสิ่งที่ต้องส่งจริง ตั้งใจให้เห็นภาพรวมของเครื่องมือบริหารจัดการและติดตามงานที่ทันสมัย ทีมเลือกใช้เท่าที่ช่วยให้ทำงานได้จริง การใช้หรือไม่ใช้ Trello ไม่มีผลต่อคะแนน

เริ่มใช้ Trello Kit

Trello เป็นเครื่องมือทางเลือกสำหรับ Monitor งานของแต่ละทีม ผู้เข้าแข่งขันยังใช้ Notion หรือ Excel และ MS Word ได้ กรรมการจะให้ Template ในวันแข่งขัน การส่งงานยึดแบบฟอร์ม ช่องทาง และเวลาตามประกาศ

ข้อมูลโรงเรือนใน Kit เป็นสถานการณ์สมมติสำหรับสาธิตวิธีบันทึก ไม่ใช่โจทย์แข่งขันหรือผลงานจริง ชื่อไฟล์หลักฐานเป็นตัวอย่าง ไม่มีไฟล์ทดสอบหรือ URL หลักฐานจริงแนบมา

ทำตามลำดับนี้

  • เปิด BOARD_EXAMPLE.html เพื่อเห็นโครงสร้างบอร์ดตัวอย่าง
  • อ่านคู่มือ Trello แล้วสร้าง Board และ Lists ตาม board_setup/LISTS.txt
  • สร้างชื่อการ์ดจาก titles_by_list แล้วใส่ Description และ Checklist จาก example_cards
  • ดู CARD_CATALOG.html หากต้องการอ่านหรือคัดลอกทั้งหมดในหน้าเดียว
  • เริ่มทีมจริงด้วย practice_templates ไม่คัดลอกผลผ่านของตัวอย่าง
  • ติดตั้ง Power-Up ตามต้องการ คู่มือแยกตัวฟรีกับ trial ให้แล้ว

การส่งงาน

เวลาส่งแผน Risk และรายงานใช้ xx.xx น. ไว้ก่อน Template Excel และ MS Word จะได้รับในวันแข่งขัน ใช้บอร์ดเพื่อ Monitor ระหว่างวันแล้วสรุปส่งตามแบบกรรมการ

สิ่งที่ไฟล์ชุดนี้ทำให้

ให้ตัวอย่างและข้อความสำหรับตั้งค่าบอร์ด ไม่มีการสร้างบอร์ดหรือเชื่อมบัญชี Trello/Power-Up ให้อัตโนมัติ ไม่ต้องใช้ API key หรือสคริปต์เพื่อตั้งค่าตามคู่มือ

ข้อความการ์ดมี 2 ชุด ใช้คนละจุดประสงค์

👀 ไว้ดูเป็นตัวอย่าง

example_cards

  • การ์ดโรงเรือนสมมติที่กรอกครบแล้ว
  • ใช้ดูว่าการ์ดที่ดีเขียนอย่างไร และลองสร้างบอร์ดทดลอง
  • ห้ามใช้เป็นบอร์ดของทีม และห้ามคัดลอกผลผ่านของตัวอย่าง
🏁 ไว้ใช้จริงวันแข่ง

practice_templates

  • แบบเปล่าสำหรับงาน Risk Issue Decision Checkpoint และรายงาน
  • สร้างบอร์ดของทีมและเตรียม List กับ Label ให้เสร็จก่อนวันแข่ง
  • วันแข่งคัดลอกแบบเปล่าไปสร้างการ์ดจริง แล้วกรอกด้วยเหตุการณ์ของทีม
