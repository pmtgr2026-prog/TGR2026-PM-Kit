คู่มือ Power-Up

คู่มือเลือก Power Up สำหรับ Trello Free

Trello Free เปิด Power-Up ได้ แต่ผู้พัฒนาแต่ละตัวอาจเก็บค่าบริการแยก คำว่าเปิดบน Free ได้จึงไม่เท่ากับใช้ทุกฟังก์ชันฟรีต่อเนื่อง

ในหน้านี้ตั้ง Dashcards และเชื่อมหลักฐานRelation และ Dependency เลือกแบบใดฟิลด์เสริม ปฏิทิน และแหล่งอ้างอิง
ย้ำ

ของที่ส่งจริง ส่งด้วย Excel และ MS Word ตาม Template ที่กรรมการจะแจกให้ในวันแข่ง ผ่านช่องทางและเวลาที่กรรมการประกาศ (ในเอกสารนี้เขียนเวลาเป็น xx.xx น. ไว้ก่อน)

ตัวอย่างใน Kit นี้อาจมีเนื้อหามากกว่าสิ่งที่ต้องส่งจริง ตั้งใจให้เห็นภาพรวมของเครื่องมือบริหารจัดการและติดตามงานที่ทันสมัย ทีมเลือกใช้เท่าที่ช่วยให้ทำงานได้จริง การใช้หรือไม่ใช้ Trello ไม่มีผลต่อคะแนน

GitHubอ้าง PR commit issue เป็นหลักฐานใช้เมื่อตัวงานอยู่ใน GitHub และผู้ใช้มีสิทธิ์ repository

เริ่มน้อยและใช้ให้ตรงปัญหา

แนะนำ Dashcards กับ Google Drive ก่อน ทีมพัฒนาซอฟต์แวร์เพิ่ม GitHub ถ้าต้องการ ส่วน Calendar และ Amazing Fields เลือกตามความจำเป็น

ไม่มีการผูก Power-Up เหล่านี้เข้าบัญชีให้ในไฟล์ Kit ให้เปิด Board แล้วเลือก Power-Ups แล้วเลือก Add Power-Ups ค้นชื่อ ตรวจผู้พัฒนา แล้วกด Add ตามขั้นตอนของแต่ละตัว

ตั้ง Dashcards และเชื่อมหลักฐาน

Dashcards สำหรับภาพรวมของทีม

  • เพิ่ม Dashcards แล้วเปิดปุ่ม Track บนหัวบอร์ด
  • เลือก Customize และเลือกบอร์ดของทีม
  • สร้างตัวนับ “งานติดขัด” โดยกรอง List ติดขัด และ Label งาน
  • สร้างตัวนับ “งานรอตรวจ” โดยกรอง List เสร็จรอตรวจ และ Label งาน
  • สร้างตัวนับ “Must ยังไม่ Done” โดยเลือก Label Must และเลือก List งานที่ยังไม่ Done

ถ้าเมนูตัวกรองรองรับการเลือกหลาย List ให้เลือก List 01 ถึง 04 สำหรับงาน Must ที่เหลือ หากไม่สะดวก ให้ทำตัวนับ Must แยกตาม List แล้วอ่านประกอบกัน ตัวอย่างจบรอบแรกมีงานติดขัด 0 รอตรวจ 2 และ Must ยังไม่ Done 1

อย่านับ Risk Report หรือการ์ดข้อมูลเป็นงาน และอย่าใช้จำนวน Done เป็นคะแนนคุณภาพ Dashcards แบบ alerts ต้อง Premium/Enterprise ส่วนการกรอง native Custom Fields ต้องมีแพ็กเกจที่รองรับ [1]

Google Drive สำหรับหลักฐาน

เพิ่ม Google Drive เปิดการ์ด แล้วเลือก Google Drive แล้วเลือก Attach a File หรือ Attach a Folder เชื่อมบัญชีของตนแล้วเลือกไฟล์ เขียน Evidence ID และจุดที่ต้องดูใน Description ด้วย ไฟล์ยังอยู่ใน Drive การแนบไม่ได้เปิดสิทธิ์ให้คนอื่นเอง [2]

GitHub สำหรับงานพัฒนา

เพิ่ม GitHub และเชื่อมบัญชีที่มีสิทธิ์ repository แล้วแนบ PR commit หรือ issue กับการ์ด Task ID ที่ตรงกัน อธิบายว่าหลักฐานยืนยันอะไร การมี commit ไม่ได้แทนผลทดสอบหรือ AC ที่ผ่าน [3]

Relation และ Dependency เลือกแบบใด

ตัวเลือกเชื่อมอะไรค่าใช้จ่ายหรือข้อจำกัด
Checklist และลิงก์การ์ดงานก่อน ถึง หลัง หรือการ์ดที่เกี่ยวข้องใช้ฟรีด้วยฟังก์ชันพื้นฐาน ต้องดูแลสถานะเอง
Card Dependencies by Screenfulblocks/blocked by related และ parent/child ข้ามบอร์ดมี trial 7 วัน หลังจากนั้นเป็น subscription แยก
Amazing Fields Card Referenceอ้างการ์ดเป็นฟิลด์ต้อง Advanced ขึ้นไป ไม่รวม Free
Planyway Dependenciesdependency ในการวางแผนอยู่ในแผนเสียเงิน ไม่รวมแผน Free

ใน Kit ให้เริ่มจากวิธีฟรีในคู่มือ Trello หน้า 4 และ RELATION_MAP.md ส่วน Screenful ใช้สาธิตเป็นตัวเลือกเสริมได้ แต่ไม่กำหนดเป็นเงื่อนไขแข่งขันหรือบอกว่าฟรีถาวร [4][5][6]

ถ้าทดลอง Screenful

  • เพิ่ม Card Dependencies by Screenful และตรวจเงื่อนไข trial ของผู้พัฒนา
  • เลือก T03 แล้วกำหนด blocked by T02; ตรวจความสัมพันธ์จากทั้งสองการ์ด
  • ใช้ related สำหรับ I01 กับ D01 แยกจาก dependency ของลำดับงาน
  • อ่านว่า Power-Up กำหนด Done อย่างไร ก่อนใช้สถานะ resolved เป็นข้อสรุป
  • ถ้าจะใช้ฟรีต่อหลัง trial ให้บันทึกรหัสและลิงก์การ์ดสำคัญใน Description ด้วย

ความสัมพันธ์ช่วยให้เห็นผลกระทบ แต่ไม่ใช่การรับรองว่าแผนเวลาถูกต้อง หรือหลักฐานการตรวจ AC และ DoD ครบแล้ว

ฟิลด์เสริม ปฏิทิน และแหล่งอ้างอิง

Amazing Fields แบบ Free

เพิ่ม Power-Up และเปิด Settings สร้างเพียง 3 ฟิลด์ เช่น ผ่าน AC ผ่าน DoD เป็น dropdown และประมาณเวลาเป็น number เก็บ Priority และรอบไว้ใน Labels แทน ไม่ตั้งสูตรคูณ Risk หรือ Card Reference เพราะไม่อยู่ใน Free [5]

ผู้พัฒนามี trial ฟังก์ชันระดับสูง ตอนทดลองให้ตรวจว่าแต่ละฟิลด์อยู่ใน Free จริง และอย่าพึ่งการแก้ฟิลด์ผ่านแอปมือถือ ใช้เว็บคอมพิวเตอร์เป็นหลัก

Calendar Power Up

เพิ่ม Calendar แล้วเปิดปฏิทินจากหัวบอร์ด การ์ดต้องมี Due date จึงแสดงตามกำหนด [7] ช่วงที่เวลาส่งยังเป็น xx.xx ให้เขียนใน Description ก่อน อย่ากรอกเวลาเดาในช่อง Due date ของงานส่ง
