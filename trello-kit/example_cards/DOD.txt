=== คัดลอกส่วนนี้ลง Description ===
ตกลงร่วมกันก่อนทำงาน และบันทึกวันเวลาและผู้ร่วมตกลง

1. งานโค้ดอยู่ใน Git และระบุ Task ID — เปิด commit และไฟล์ที่เปลี่ยน
2. มีคนที่ไม่ได้ทำงานนั้นตรวจ AC — ผลตรวจระบุผู้ตรวจและผลที่ได้
3. เก็บหลักฐานและอ้าง Evidence ID — เปิดไฟล์ทดสอบและระบุจุดที่ยืนยัน
4. ถ้า contract เปลี่ยนแจ้งทีมและอัปเดต — ตรวจเวอร์ชัน contract และบันทึกแจ้ง

Checklist ใน Kit แสดงเงื่อนไขที่ต้องตรวจ ไม่ได้ยืนยันว่ามีหลักฐานจริง
