คู่มือ Notion สำหรับติดตามงานทีม

Notion เป็นเครื่องมือทางเลือกสำหรับติดตามงานของทีม ผู้เข้าแข่งขันสามารถใช้ Excel และ MS Word ได้ โดยกรรมการจะให้ Template ในวันแข่งขัน การส่งงานให้ยึดแบบฟอร์ม ช่องทาง และเวลาที่กรรมการประกาศ

ในหน้านี้นำเข้าหน้าแรกและตารางตั้งค่าคอลัมน์และเพิ่มงานทำบอร์ดและมุมมองติดตามงานอัปเดตงานและสรุปรายงานแชร์ เก็บสำเนา และแก้ปัญหาทั่วไปเริ่มจาก Template หรือสร้างเองจัดหน้า Dashboard ให้เหมือนตัวอย่างตั้งมุมมองและกราฟในหน้าแรกสร้าง Relation และเชื่อม Taskเชื่อมบันทึกกับงานที่เกี่ยวข้องเปิดเส้น Dependency ใน Timelineตรวจสำเนาก่อนเริ่มแข่งขัน
ย้ำ

ของที่ส่งจริง ส่งด้วย Excel และ MS Word ตาม Template ที่กรรมการจะแจกให้ในวันแข่ง ผ่านช่องทางและเวลาที่กรรมการประกาศ (ในเอกสารนี้เขียนเวลาเป็น xx.xx น. ไว้ก่อน)

ตัวอย่างใน Kit นี้อาจมีเนื้อหามากกว่าสิ่งที่ต้องส่งจริง ตั้งใจให้เห็นภาพรวมของเครื่องมือบริหารจัดการและติดตามงานที่ทันสมัย ทีมเลือกใช้เท่าที่ช่วยให้ทำงานได้จริง การใช้หรือไม่ใช้ Notion ไม่มีผลต่อคะแนน

ใช้เป็นทีม 1 ทีม 1 Workspace

จุดสำคัญเมื่อใช้เป็นทีม
  • ให้ 1 คนสร้าง Workspace แล้วเชิญเพื่อนร่วมทีมผ่านปุ่ม Share ของหน้าแรกเป็น Guest พร้อมสิทธิ์แก้ไข เพื่อหลีกเลี่ยงข้อจำกัดจำนวน block ของ Workspace ฟรีที่มีสมาชิกหลายคน (Notion Help เรื่อง block usage)
  • แผนฟรีเชิญ Guest ได้สูงสุด 10 คนต่อ Workspace เพียงพอสำหรับทีม 5 คน และยังเหลือที่ให้เชิญกรรมการเข้าดูได้
  • อัปโหลดไฟล์ได้ ไม่เกิน 5 MB ต่อไฟล์ คลิปหรือหลักฐานขนาดใหญ่ให้เก็บใน Drive แล้ววางลิงก์ใน Notion (หน้าราคาของ Notion)

รูปแบบที่เหมาะคือ แต่ละทีมมี Workspace ของตนเอง เจ้าของ 1 คน และเพื่อนร่วมทีมเป็น Guest

เรียนรู้เฉพาะส่วนที่ต้องใช้

คู่มือนี้แนะนำการนำเข้าไฟล์ ตั้งคอลัมน์ ทำบอร์ด ติดตามงาน และเก็บสำเนาก่อนส่ง ใช้ Table และ Board เป็นหลัก ส่วน Dashboard ฉบับล่าสุดมี Timeline และ Relation เพิ่มเติม ดูขั้นตอนท้ายเล่ม โดยไม่ต้องใช้ Notion AI

คำใน Notionความหมายใน Kit
Pageหน้าเอกสาร เช่น หน้าแรกของทีม หรือรายงานหนึ่งรอบ
Databaseฐานข้อมูล เช่น รายการแผนงานหรือ Risk
Propertyคอลัมน์ เช่น Owner สถานะ และวันเวลา
Itemหนึ่งรายการ เช่น T02 ซึ่งเปิดเป็นหน้าเพื่อเพิ่มรายละเอียดได้
Viewมุมมองข้อมูลชุดเดิม เช่น Table หรือ Board
Filter และ Groupเลือกแถวที่ต้องการเห็น และจัดกลุ่มรายการ

เตรียมก่อนเริ่ม

  • เข้าสู่บัญชี Notion ของทีมในเว็บหรือแอปคอมพิวเตอร์
  • แตก ZIP นี้ให้เรียบร้อย และเลือก notion_example สำหรับลองทำ
  • ให้หนึ่งคนเป็นผู้ตั้งค่า แล้วค่อยแชร์ให้สมาชิกช่วยอัปเดต
  • ชื่อเมนูอาจต่างตามภาษาและหน้าตาเวอร์ชันที่บัญชีใช้

ทำตามเมนูทีละขั้นและตรวจผลหลังนำเข้า หากชื่อเมนูต่างจากคู่มือ ให้ดูเอกสาร Notion Help ที่ระบุท้ายเล่มประกอบ

เมื่อต้องการเริ่มของทีมจริง

ทำขั้นตอนเดิมซ้ำอีกรอบกับ notion_practice เพียงชุดเดียว แยกเป็นหน้าใหม่ ไม่ปนกับหน้าทดลองของตัวอย่าง เปลี่ยน T00 เป็นรหัสทีมจริงก่อนใช้งาน ชุดนี้มีรายการตั้งค่า 1 แถวต่อฐานหลักและรายงานร่าง 3 รอบ ให้ลบแถวตั้งค่าเมื่อกำหนดชนิดคอลัมน์แล้ว

CSV นำเข้าเป็นฐานข้อมูล ส่วน Markdown เป็นหน้าเอกสาร การนำเข้าไม่ได้สร้าง Board Timeline Formula หรือ Relation ให้อัตโนมัติ จึงต้องตั้งค่าตามหน้าถัดไป

อย่านำเข้าซ้ำลงฐานเดิมเพื่ออัปเดตงาน เพราะ import และ merge CSV เพิ่มแถว ไม่ได้อัปเดตแถวเก่า หากทดลองผิด ให้ลบฐานทดลองนั้นแล้วเริ่มใหม่แทนการนำเข้าซ้อน [1]

ตั้งค่าคอลัมน์และเพิ่มงาน

คลิกชื่อคอลัมน์แล้วเลือก Edit property หรือเมนูประเภทข้อมูล ตั้งเฉพาะคอลัมน์หลักก่อน รายละเอียดครบทุกฐานอยู่ใน field_reference.md

คอลัมน์ชนิดที่ใช้ข้อควรดู
งาน หรือคอลัมน์แรกTitleหัวข้อรายการที่เปิดเป็นหน้าได้
ทีม รอบ PrioritySelectเลือกค่าให้สะกดเหมือนกัน
สถานะStatusยังไม่เริ่ม กำลังทำ ติดขัด เสร็จรอตรวจ Done
Owner และรหัสอ้างอิงTextเริ่มด้วยชื่อ/รหัส ไม่จำเป็นต้องเชื่อม People
เริ่มและสิ้นสุดตามแผนDate พร้อมเวลาตรวจวันเดือนปีและเวลาไทยก่อนใช้ Timeline
เริ่มและสิ้นสุดจริงDate พร้อมเวลายังไม่เสร็จให้สิ้นสุดจริงว่าง
เสร็จ %Number แบบตัวเลขค่า 0 ถึง 100 เช่น 50 ไม่ตั้งรูปแบบ Percent
ผ่าน AC และผ่าน DoDSelectยังไม่ตรวจ ผ่าน ไม่ผ่าน หรือ ไม่เกี่ยวข้อง
URL หลักฐานURLกรอกหนึ่ง URL ต่อช่อง รายการอื่นใส่ในหน้า
โอกาส รุนแรง ระดับNumberระดับ = โอกาสคูณความรุนแรง กรอกปรับเอง

เพิ่มงานหนึ่งใบ

กด New หรือแถวว่าง ตั้ง Task ID ระบุงาน Owner Priority dependency วันเวลา และ AC เปิดรายการนั้นเพื่อใส่รายละเอียดหรือหลายลิงก์ ตั้งสถานะเริ่มต้น “ยังไม่เริ่ม”

ถ้าวันเวลาจาก CSV ยังเป็น Text ให้ตรวจเทียบค่าต้นฉบับแล้วตั้งเป็น Date อย่าตีความ xx.xx เป็นเวลาในคอลัมน์ Date ให้ใส่ xx.xx ในช่องเวลาส่งงานซึ่งเป็น Text เท่านั้น [1]

ทำบอร์ดและมุมมองติดตามงาน

Board ตามสถานะ

  • เปิดฐานแผนงาน กด + ข้างชื่อมุมมอง แล้วเลือก Board
  • เลือก Group เป็น “สถานะ”
  • เปิด Property visibility เพื่อแสดง Task ID Owner Priority และผ่าน AC
  • ตั้ง Filter เป็นทีมของตนและรอบที่กำลังทำงาน
  • ลากการ์ดไปคอลัมน์ใหม่เมื่อสถานะเปลี่ยน แล้วเปิดการ์ดเพิ่มหลักฐาน

การลากการ์ดเปลี่ยนค่าสถานะ ไม่ได้ตรวจ AC หรือ DoD ให้ทีม ต้องตรวจและบันทึกผลแยกก่อนเลื่อนไป Done [2]

เพิ่มมุมมองที่ช่วยตัดสินใจ

ชื่อมุมมองตั้งค่าแนะนำ
งาน MustTable กรอง Priority = Must และรอบปัจจุบัน
งานติดขัดTable กรองสถานะ = ติดขัด แสดง Owner และต่อจาก
งานรอตรวจTable กรองสถานะ = เสร็จรอตรวจ แสดง AC และหลักฐาน
Risk ของรอบนี้Table กรองรอบปัจจุบัน เรียงระดับจากมากไปน้อย

Timeline เป็นทางเลือก

ถ้าทีมต้องการดูช่วงเวลา กด + เพิ่ม Timeline แล้วเลือก Layout แล้วเลือก Show timeline by กำหนดเริ่มและสิ้นสุดตามแผนเป็นคนละ property หรือสร้าง Date ที่มีช่วงเวลาเดียวกัน ตรวจว่าทั้งสองช่องเป็น Date จริง [3]

หลังนำเข้า CSV ค่า dependency ยังเป็นข้อความ ต้องสร้าง Relation และเปิด Dependencies ตามขั้นตอนท้ายเล่ม จึงจะเห็นเส้นเชื่อมใน Timeline

อัปเดตงานและสรุปรายงาน

ทำงานประจำวัน

  • เริ่มงานแล้วใส่เริ่มจริงและสถานะกำลังทำ
  • เมื่อติดปัญหา บันทึก Issue พร้อมผลกระทบและ Owner
  • ถึงจังหวะทบทวน บันทึก Checkpoint และเหตุผลคงหรือปรับแผนใน Decision log
  • ทำเสร็จให้เป็นเสร็จรอตรวจ เมื่อผ่าน AC และ DoD แล้วจึงเป็น Done
  • อัปเดต Risk เมื่อมีข้อมูลใหม่ และตรวจว่าระดับยังตรงกับโอกาสคูณความรุนแรง

เชื่อมเรื่องราวด้วยรหัสก่อน

เก็บรหัส T02 R01 I01 D01 ไว้สำหรับรายงาน Excel และ Word และเพิ่ม Relation ตามขั้นตอนท้ายเล่มหากต้องการให้กดเปิดรายการที่เกี่ยวข้องจาก Dashboard ได้

สร้างรายงานแต่ละรอบ

  • เปิดฐาน Daily Report เลือกรอบที่ต้องการและเปิดเป็นหน้า
  • นำเนื้อหา 9_แบบฝึกรายงาน.md มาใส่ แล้วตอบด้วยเหตุการณ์จริง
  • อ้างแผนและ Risk ฉบับส่ง แทนการคัดลอกตารางทั้งหมด
  • ใส่หลักฐานพร้อมจุดที่ต้องดู และระบุข้อจำกัดของผลทดสอบ
  • ย้ายเนื้อหาที่เกี่ยวข้องลง Template ของกรรมการในวันแข่งขัน

เก็บสำเนาก่อนส่ง

เปิดเมนู ••• แล้วเลือก Export แล้วเลือก Markdown & CSV และเลือก Include subpages เมื่อต้องการหน้าลูก ตรวจไฟล์ที่ได้อีกครั้ง เก็บสำเนาแผน Risk รายงาน และหลักฐานด้วยรหัสเช่น T01-R1-v1 ก่อนแก้บอร์ดต่อ [5]

ไฟล์ส่งออก Notion ใช้สำรองและอ้างอิง ไม่ได้แทน Template Excel หรือ Word ของกรรมการโดยอัตโนมัติ ส่งงานตามประกาศที่เวลา xx.xx น. หากมีการแก้หลังส่ง ให้แยก v2 และแจ้งตามขั้นตอนกรรมการ

ตรวจสอบเอกสารวันที่ 13 พฤศจิกายน 2569 เมนูอาจเปลี่ยนตามเวอร์ชันและสิทธิ์บัญชี

เริ่มจาก Template หรือสร้างเอง

ฉบับปรับปรุง 13 พฤศจิกายน 2569 ให้ได้โครงหน้า PM Board ล่าสุด คู่มืออยู่ในไฟล์ Kit แยกจากหน้า Dashboard

วิธีผลที่ได้
คัดลอก Templateรักษาโครงหน้า สี มุมมอง และฐานข้อมูลได้ใกล้ต้นฉบับที่สุด ต้องมีลิงก์ที่กรรมการเปิดให้ Duplicate
สร้างเองจาก CSVข้อมูลเริ่มต้นเหมือน Kit แต่ต้องตั้งค่าฐาน Relation มุมมอง และจัดหน้าเพิ่มตามขั้นตอนนี้

หน้าอ้างอิงของกรรมการ https://app.notion.com/p/4167e648b80d81a9b12bc6ef5e9bf51d

ลิงก์ข้างต้นเป็นหน้าอ้างอิง ยังไม่ได้ยืนยันว่าเผยแพร่สาธารณะหรือเปิด Duplicate แล้ว หากเปิดไม่ได้ให้ใช้ลิงก์ Template ที่กรรมการแจก หรือตามวิธีสร้างเอง

เมื่อกรรมการแจก Template ที่คัดลอกได้

  • เข้า Notion เปิดลิงก์ แล้วกด Duplicate มุมขวาบน เลือก workspace ของทีม
  • คัดลอกทั้งหน้าและหน้าลูก ข้อมูลและบันทึกของทีม ห้ามคัดลอกเฉพาะ linked view
  • ตั้งชื่อ ทีม Txx TGR2026 PM Board เปลี่ยนรหัสทีมและชื่อสมาชิก
  • ทดลองแก้ชื่อ Task ในสำเนา ตรวจว่าต้นฉบับไม่เปลี่ยน และ Relation ชี้เข้าฐานในสำเนา
  • ถ้าพบ No access หรือ Relation กลับไปต้นฉบับ ให้เลือกฐานข้อมูลของสำเนาใหม่ก่อนใช้จริง

เมนูและระยะห่างอาจต่างตามเวอร์ชัน ขนาดจอ และสิทธิ์บัญชี ใช้โครงหน้าและการทำงานเป็นเกณฑ์ตรวจ

จัดหน้า Dashboard ให้เหมือนตัวอย่าง

  • เปิดหน้าแรก เมนู ••• เปิด Full width เพิ่มไอคอนต้นอ่อนและ Cover โทนเขียว
  • สร้างหน้าลูกชื่อ ข้อมูลและบันทึกของทีม แล้วย้ายฐานต้นทางทั้ง 8 เข้าไป
  • ที่ส่วนบนสร้างสองคอลัมน์ด้วยการลากจุดจับบล็อกไปทางขวาจนเห็นเส้นแนวตั้ง ปรับซ้ายประมาณ 60% ขวา 40%
  • ฝั่งซ้ายเพิ่ม Callout ภาพรวม 3 รอบ แบ่งเป็น 3 กลุ่มข้อความ รอบ 1 วันที่ 12 พ.ย. รอบ 2 วันที่ 12 พ.ย. รอบ 3 วันที่ 12 พ.ย. ใช้ xx.xx สำหรับเวลาส่ง
  • ใต้ภาพรวม เพิ่มกล่อง ไปที่ สีชมพู และ ลิงก์สำคัญ สีเขียว วางลิงก์ไปส่วนแผน Risk Checkpoint Decision Issue DoD หลักฐาน และแบบฟอร์มกรรมการ
  • ฝั่งขวาวางกราฟ Must และ Gallery ทีมตามหน้าถัดไป
  • ใต้สองคอลัมน์ วางหัวข้อ แผนวันนี้ ตามด้วย Board และ Timeline เต็มความกว้าง แล้ว Risk ของรอบนี้ และ Decision log ตามลำดับ

เชื่อมข้อมูลเดิมเข้าหน้าแรก

พิมพ์ /linked เลือก Linked view of database แล้วเลือกฐานที่อยู่ในหน้าลูก สร้างมุมมองแต่ละส่วนจากฐานเดิม ห้ามนำเข้า CSV ใหม่เพื่อทำแต่ละมุมมอง

สำหรับลิงก์ลัด คลิกเมนูของหัวข้อแล้ว Copy link to block นำไปวางในกล่อง ไปที่ ส่วนลิงก์สำคัญใช้ URL จริงที่กรรมการให้ อย่าใช้ลิงก์ตัวอย่างเป็นปลายทางส่งงาน

ภาพรวมรอบและข้อความสรุปใน Callout ต้องอัปเดตเอง ส่วน Board Timeline และกราฟอ่านข้อมูลจากฐาน

เปิดเส้น Dependency ใน Timeline

Relation ปกติช่วยให้เปิดงานที่เกี่ยวข้องได้ แต่ไม่ได้ยืนยันว่ามีเส้นลูกศรบน Timeline ต้องเปิด Dependencies ของฐานข้อมูลใน Notion เพิ่ม ขั้นตอนนี้ทำในหน้า Notion โดยผู้ใช้

  • เปิดฐานแผนงาน เลือกเมนูตั้งค่าฐานข้อมูล แล้วเลือก More settings แล้วเลือก Dependencies
  • เลือก Do not automatically shift ระหว่างฝึก เพื่อรักษาวันเวลาตัวอย่าง แล้ว Turn on dependencies
  • ตรวจ Property ที่ Notion ใช้สำหรับ dependency ถ้ามีตัวเลือกใช้ Relation เดิม ให้จับคู่ งานก่อนหน้า กับด้านที่ถูกบล็อก และ งานถัดไป กับด้านที่บล็อกงานอื่น
  • ถ้าเวอร์ชันที่ใช้สร้าง Property ใหม่ เช่น Blocked by และ Blocking ให้กรอกคู่ T01 ถึง T09 ตามตารางหน้าก่อนใน Property ที่สร้างใหม่ อย่าสมมติว่า Relation เดิมถูกใช้แล้ว
  • กลับ Timeline เลื่อนเมาส์ที่ขอบแถบงานจนมีจุดหรือลูกศร ลากจากงานก่อนหน้าไปงานถัดไป หรือเลือกผ่านช่อง dependency แล้วตรวจทิศทางว่า T02 ถูกบล็อกโดย T01
  • ตรวจทั้ง 9 เส้น โดยเฉพาะ T09 ต้องมีต้นทางสองงานคือ T03 และ T07 หากไม่เห็นเส้น ให้ตรวจว่าใช้ Property dependency จริงและทั้งสองงานอยู่ในมุมมอง

การเลื่อนแผนทำได้หลังทีมตัดสินใจและบันทึกเหตุผล หากต้องการเปิดเลื่อนวันอัตโนมัติ ให้เลือกนโยบายใหม่ใน Dependencies และตรวจผลทุกงานที่กระทบ

เกณฑ์ผ่านขั้นตอนนี้คือเห็นลูกศรใน Timeline จริง การเห็นชื่อในช่อง Relation อย่างเดียวยังไม่ผ่าน

ตรวจสำเนาก่อนเริ่มแข่งขัน

  • หน้าแรกมีสองคอลัมน์ด้านบน Board และ Timeline เต็มความกว้างด้านล่าง ไม่มีคู่มืออยู่ในหน้า Dashboard
  • ฐานหลักครบ 8 ฐานอยู่ในหน้าลูก Linked view ทั้งหมดชี้เข้าฐานของทีมตนเอง
  • เปลี่ยนรหัสทีม สมาชิก งาน และวันที่ให้ตรงกับทีม ทดลองแก้ Task หนึ่งรายการแล้ว Board กับ Timeline เปลี่ยนตรงกัน
  • เลือก Filter รอบให้ตรงกันทุกมุมมอง Quick filter แต่ละมุมมองไม่เชื่อมกันอัตโนมัติ
  • ตรวจ Relation งานก่อนหน้า งานถัดไป ผู้รับผิดชอบ และบันทึกปลายทาง
  • หากต้องการลูกศรบนกราฟ ให้ตรวจว่าเปิด Dependencies และเห็นครบตามลำดับงาน
  • สำหรับเริ่มงานจริง ล้างข้อมูลสมมติในสำเนาอย่างระมัดระวัง แล้วเติมงานและ Relation ของทีม ตรวจกราฟอีกครั้ง
  • เวลาส่งงานยังเป็น xx.xx จนกรรมการประกาศ ทุกการผ่าน AC และ DoD ต้องมีผลตรวจและหลักฐานจริง
  • แชร์สำเนาให้เพื่อนแล้วทดลองเปิดหน้า Task กับหลักฐานจากบัญชีเพื่อน เก็บ Snapshot ก่อนส่งตามขั้นตอนเดิม
