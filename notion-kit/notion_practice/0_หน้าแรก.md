# T00 PM Board

Notion เป็นเครื่องมือทางเลือกสำหรับติดตามงานของทีม ผู้เข้าแข่งขันสามารถใช้ Excel และ MS Word ได้ โดยกรรมการจะให้ Template ในวันแข่งขัน การส่งงานให้ยึดแบบฟอร์ม ช่องทาง และเวลาที่กรรมการประกาศ

## ใช้บอร์ดนี้อย่างไร

1. กรอกสมาชิก แผน Risk และตกลง DoD
2. อัปเดตงานและหลักฐานระหว่างวัน
3. ทบทวนที่ Checkpoint บันทึกเหตุผลคงหรือปรับแผน
4. สรุปรายงานและย้ายข้อมูลลง Template ที่ได้รับในวันแข่งขัน
