# TGR2026 PM Kit

Kit ตัวอย่างเครื่องมือสื่อสารและติดตามงานของทีม สำหรับผู้เข้าแข่งขัน TESA Top Gun Rally 2026 (16 ถึง 20 พ.ย. 2569)

เปิดอ่านแบบเว็บได้ที่ https://pmtgr2026-prog.github.io/TGR2026-PM-Kit/

## อ่านก่อน

- Notion และ Trello ใน Kit นี้เป็นเพียงเครื่องมือที่แนะนำ เพื่อการสื่อสารกับทีม ในการบริหารจัดการ และ Monitor งาน ไม่ใช่ข้อบังคับ และไม่มีผลต่อคะแนน
- ผู้เข้าแข่งขันอาจใช้เครื่องมืออื่น เช่น Miro Jira Asana หรืออื่น ๆ ได้ตามความถนัด
- ของที่ส่งจริง ส่งด้วย Excel และ MS Word ตาม Template ที่กรรมการจะแจกให้ในวันแข่ง ผ่านช่องทางและเวลาที่กรรมการประกาศ (ในเอกสารนี้เขียนเวลาเป็น xx.xx น. ไว้ก่อน)
- ตัวอย่างใน Kit อาจมีเนื้อหามากกว่าสิ่งที่ต้องส่งจริง ตั้งใจให้เห็นภาพรวมของเครื่องมือบริหารจัดการและติดตามงานที่ทันสมัย
- การอบรม PM วันที่ 16 พ.ย. ไม่สอนการใช้เครื่องมือ ทีมที่จะใช้ให้ตั้งค่าและลองใช้มาก่อนล่วงหน้า

## เริ่มจากตรงไหน

- [หน้ารวม Kit](https://pmtgr2026-prog.github.io/TGR2026-PM-Kit/)
- [Notion Kit](https://pmtgr2026-prog.github.io/TGR2026-PM-Kit/notion-kit/START_HERE.html) มีหน้าตัวอย่างที่กด Duplicate ได้ และคู่มือสำหรับผู้เริ่มต้น
- [Trello Kit](https://pmtgr2026-prog.github.io/TGR2026-PM-Kit/trello-kit/START_HERE.html) มีบอร์ดตัวอย่าง ข้อความการ์ด และคู่มือ

ถ้าต้องการไฟล์ทั้งชุด กดปุ่ม Code สีเขียว แล้วเลือก Download ZIP

## ในโฟลเดอร์มีอะไร

- `index.html` หน้ารวม
- `notion-kit/`
  - `START_HERE.html` และ `guides/` คู่มือ 2 หน้า
  - `notion_example/` ข้อมูลโรงเรือนสมมติที่กรอกแล้ว ไว้ดูเป็นตัวอย่าง
  - `notion_practice/` ชุดเปล่าของทีม ไว้ใช้จริงวันแข่ง
  - `field_reference.md` ชนิดคอลัมน์สำหรับตั้งค่าหลังนำเข้า
- `trello-kit/`
  - `START_HERE.html` `BOARD_EXAMPLE.html` `CARD_CATALOG.html` และ `guides/` คู่มือ 2 หน้า
  - `example_cards/` การ์ดตัวอย่างที่กรอกแล้ว ไว้ดูเป็นตัวอย่าง
  - `practice_templates/` แบบเปล่า ไว้ใช้จริงวันแข่ง
  - `board_setup/` รายชื่อ List Label และแผนเชื่อมการ์ด
